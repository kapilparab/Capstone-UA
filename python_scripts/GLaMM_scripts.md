### Scripts for testing GLaMM inference can be found in the [forked repository](https://github.com/VeraJSolo/groundingLMM-UA), under "capstone_testing" folder

#### 🔮 To test inference, use script [infer.py](https://github.com/VeraJSolo/groundingLMM-UA/blob/main/capstone_testing/scripts/infer.py) 
Inference will produce a .json output.
#### 🎨 To visualize the inference mask, use script [maskimage.py](https://github.com/VeraJSolo/groundingLMM-UA/blob/main/capstone_testing/scripts/maskimage.py) on the .json output.
#### 📈 To evaluate performance of inference, use script [evaluation.py](https://github.com/VeraJSolo/groundingLMM-UA/blob/main/capstone_testing/scripts/evaluation.py)
Evaluation relies on the .json output and .png ground truth. This script also exists in this repository, in [this folder](https://github.com/kapilparab/Capstone-UA/edit/main/python_scripts).
